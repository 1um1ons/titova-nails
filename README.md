# TITOVA NAILS — онлайн-запись

## Что уже работает
- Календарь выбора даты.
- Будни: 09:00 и 18:30; среда: 16:00 и 19:00.
- Суббота и воскресенье: каждый час с 10:00 до 17:00 включительно.
- Выбор услуги, имени и телефона.
- Сервер хранит бронирования в `bookings.json` и блокирует повторную запись на занятое время.
- После заявки сервер отправляет сообщение в Telegram.

## Подключение Telegram (один раз)
1. В Telegram откройте официальный аккаунт **@BotFather**, отправьте `/newbot` и следуйте подсказкам. Придумайте имя и username бота.
2. BotFather выдаст токен. Не публикуйте его и не отправляйте в открытые чаты.
3. Откройте созданного бота по его ссылке и нажмите **Start**.
4. Узнайте свой chat ID: откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` (подставьте токен вместо `ВАШ_ТОКЕН`). В ответе найдите `message` → `chat` → `id`. Не передавайте никому эту ссылку: в ней секретный токен.
5. Скопируйте `.env.example` в файл `.env` и впишите токен и chat ID.

## Запуск на компьютере
Нужен Node.js 18 или новее. В папке проекта выполните:

```bash
node server.js
```

Затем откройте `http://localhost:3000`.

## Публикация в интернете
Для работы клиентской записи круглосуточно проект нужно разместить на Node.js-хостинге. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения хостинга. Не загружайте `.env` в публичный репозиторий. Файл `bookings.json` должен храниться на постоянном диске хостинга, иначе записи могут потеряться после перезапуска.

**Важно:** сам HTML-файл при двойном нажатии открывает только внешний вид. Для реальной отправки в Telegram и блокировки занятых слотов обязательно запустить сервер. Сейчас бот не создан от вашего имени: для этого нужен ваш аккаунт Telegram и токен, который выдаёт BotFather.
